# 체형 목록 정리와 표시 선택

체형 커스텀의 기본 모델·내 체형 카드 아래에 `체형 더보기에 표시` 체크를 둔다. 체크를 꺼도 관리 화면에는 카드가 남으며, 켜면 다시 선택 목록에 나온다. 삭제·이름 변경·편집 버튼과 분리한다.

- 전체화면·플로팅바·문장 검색이 공유하는 BodyExpand에서 동일한 설정을 적용한다.
- 설치별 BFF preferences의 `pickerVisibility.hiddenPresetIds / hiddenCardIds`에 저장한다. 구 BFF에 해당 필드가 없으면 체크를 노출하지 않는다. BFF 선배포가 필요하다.
- 숨김은 현재 선택·last_used·자동 추천 정책·체형 수치·원본 자산·최종 FBX를 변경하지 않는다. 개인 카드의 기반 체형을 숨겨도 개인 카드는 독립적으로 포함/제외한다.
- 저장 실패나 revision 충돌 시 서버 값을 다시 읽는다. 창 간에는 설치 ID와 revision만 알리고, 다른 설치의 이벤트는 무시한다.
- 새 기본값/기존 기본값과 카드 데이터는 유지한다. 새 카드는 기본 표시이며, 실제 삭제한 카드의 숨김 ID만 BFF에서 정리한다.

## CSP 중복 카드 원인과 처리

2026-11-07 스테이징의 `csp-shaped-save-20261030` 카탈로그에 별도 제품 프리셋이 아닌 CSP 저장용 남성 9·여성 11종이 추가돼 있었다. 이름은 `· CSP`이고 neutralPreview가 없어 빈 카드로 노출됐다.

기본 모델·커스텀 시작 목록·후보 선택 목록에서 알려진 20개 ID만 제거한다. ID는 `pickerVisibility.ts`의 한 정책에서 판정하며, 기존 승인 프리셋과 새 default83/default80 ID에는 적용하지 않는다. 기존 카드 lookup과 진행 중 인물은 전체 카탈로그를 계속 참조하므로 원본 파일/선택을 폐기하지 않는다. S3 자산이나 카탈로그를 삭제하지 않는다.

## 검증 범위

관리 화면의 체크가 카드 삭제/편집으로 전파되지 않는지, 앱/바에서 숨김·CSP 제외가 동일한지, 선택을 유지하는지 검사한다. 별도 QueryClient를 가진 두 화면의 변경 통지·다른 설치 이벤트 무시·충돌 복구도 검사한다. 실제 native 앱/CSP E2E와 배포는 이 변경의 검증 범위가 아니다.
