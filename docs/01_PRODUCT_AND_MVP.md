# 제품 방향 및 MVP 범위

## 1. 제품 한 줄 정의

**Standin은 웹툰 러프 콘티나 화면 캡처에서 가까운 3D 인체 포즈 후보를 찾아, 작가가 비교·선택하고 포즈 파일로 저장할 수 있게 하는 빠른 PC 작업 도구다.**

---

## 2. 제품 구성

Standin은 세 영역으로 나뉜다.

| 영역 | 기술 | 역할 |
|---|---|---|
| Desktop App | Tauri | 입력, 캡처, 분석 요청, 후보 선택, 저장 |
| Analysis Server | Python FastAPI | VLM, 스켈레톤 추출, 포즈 검색, 결과 생성 |
| Web | Next.js | 랜딩페이지, 다운로드, 소개, 향후 계정·결제 |

이 문서는 Desktop App만 다룬다.

---

## 3. 제품 방향성

### 앱 중심

실제 작업은 PC 앱에서 이루어진다. 사용자는 웹 브라우저보다 작업 프로그램에 가까운 경험을 기대한다.

### 웹은 진입점

웹은 다음 역할을 맡는다.

- 서비스 소개
- 설치 파일 다운로드
- 버전 및 릴리스 안내
- 향후 계정, 결제, 도움말

### 빠르고 간편하게

앱을 실행한 뒤 메인 작업까지 최소 단계로 이동한다.

```text
앱 실행
→ 로그인 상태 확인
→ 파일 드롭 또는 캡처
→ 분석
→ 후보 선택
→ 저장
```

---

## 4. 핵심 사용자

- 웹툰 그림 작가
- 콘티와 밑그림을 직접 작업하는 개인 작가
- 클립스튜디오 3D 인체를 사용하는 작가
- 캡처한 일부 컷을 빠르게 분석하고 싶은 사용자
- 포즈를 처음부터 잡는 반복 작업을 줄이고 싶은 사용자

---

## 5. MVP 기능

### 인증

- 로그인
- 로그아웃
- 앱 재실행 시 세션 복원
- 인증 만료 처리

회원가입과 비밀번호 찾기는 MVP에서 웹으로 연결하거나 후속으로 둘 수 있다.

### 입력

#### 메인 입력

- 이미지 파일 선택
- 파일 드래그 앤 드롭
- 클립보드 이미지 붙여넣기
- 화면 캡처
- 향후 화면 녹화

#### 단축 입력

- 전역 단축키로 캡처 시작
- 향후 전역 단축키로 녹화 시작

### 분석

서버에서 담당:

- VLM 분석
- 컷 또는 인물 판별
- 스켈레톤 추출
- 포즈 검색
- 후보 생성

앱에서 담당:

- 업로드
- 분석 상태 표시
- 실패 및 재시도
- 결과 수신
- 후보 비교

### 후보 뷰어

- 포즈 후보 5개 표시
- 후보별 미리보기
- 선택 상태
- 2D 또는 3D 비교
- 정확도 대신 이해 가능한 태그와 보정 필요 상태 우선
- 선택한 후보 확대
- 다시 검색

### 출력

- 선택 결과 저장
- MVP 우선 형식: BVH
- 포즈 데이터만 저장
- 저장 위치 선택
- 파일 이름 기본값 제공
- 저장 완료 후 폴더 열기

## 6. MVP에서 명확히 결정할 항목

### “정확도” 표시 여부

추천:

- 모델 내부 점수를 그대로 퍼센트로 노출하지 않는다.
- 점수가 사용자 체감 정확도와 일치한다는 검증 전에는 `높은 일치`, `유사`, `보정 필요` 같은 단계형 상태를 사용한다.
- 후보 순서는 검색 점수에 따라 정렬한다.
- 개발자 모드에서만 원시 점수를 확인한다.

### 다시 돌리기

MVP에 포함한다.

두 종류를 구분한다.

1. `같은 입력으로 다시 검색`
   - 서버의 검색 파라미터 또는 후보 seed를 변경
2. `입력 조정 후 다시 분석`
   - 크롭, 인물 수, 샷 종류 등을 사용자가 수정한 뒤 전체 재분석

첫 MVP에서는 1번만 구현해도 된다.

### 캡처와 녹화

- 캡처는 이번 주 핵심
- 녹화는 버튼과 인터페이스 자리만 준비
- 실제 녹화·프레임 선택은 후속 스프린트

---

## 7. MVP 밖

- 포즈를 앱 안에서 정밀하게 관절 편집
- 복잡한 다중 인물 상호작용 자동 합성
- 클립스튜디오 프로젝트 직접 수정
- 웹툰 한 화 전체 자동 처리
- 로컬 모델 실행
- 실시간 영상 포즈 추적
- 팀 협업 및 코멘트
- 클라우드 포즈 라이브러리 편집 도구
- 자동 결제와 구독 관리
- 자동 업데이트 고도화

---

## 8. 성공 기준

### 제품 성공 기준

- 사용자가 1분 안에 입력을 시작할 수 있다.
- 캡처 후 분석 요청까지 흐름이 끊기지 않는다.
- 후보 5개를 비교하고 하나를 고를 수 있다.
- 실패 시 원인을 이해하고 다시 시도할 수 있다.
- 선택한 포즈를 로컬 파일로 저장할 수 있다.

### 기술 성공 기준

- UI와 네이티브 기능 경계가 명확하다.
- 서버 Mock을 실제 API로 쉽게 교체할 수 있다.
- Windows와 macOS 차이를 기능 내부에서 흡수한다.
- 두 명이 병렬 작업해도 충돌이 적은 구조다.
