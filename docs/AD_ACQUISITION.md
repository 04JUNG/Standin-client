# 광고에서 앱 사용까지

최신 앱 설치 후 랜딩의 ‘설치했어요 — 앱 열기’를 누르면 production `standin://campaign` 딥링크를 수신한다. staging/dev는 각 환경의 프로토콜만 받는다. `source=instagram`, `campaign=open-beta`, `creative=meta-poster-a|meta-hook-a` 외 입력은 거절한다. 웹 쿠키·클릭 식별자·이메일은 받지 않는다.

콜드 스타트(getCurrent)와 실행 중(onOpenUrl)을 처리한다. 앱 기본 이용 동의·설치 등록을 마친 뒤 별도의 광고 연결 선택 동의를 띄운다. pending 값은 메모리에만 두며 거절/닫기 때 폐기한다. 거절은 API 요청을 하지 않는다. 동의 시 POST `/v1/installations/current/acquisition`으로 creative, consent=true, version=2026-10-29를 보낸다. 서버는 설치 등록 24시간 이내의 첫 연결만 인정한다. 실패는 사용자를 가두지 않는다.

설정의 ‘광고 유입 연결 해제’는 DELETE로 연결을 삭제하고 앱·작업은 유지한다. 전체 데이터 삭제 시 서버에서도 연결을 제거한다. 조회·연결 API는 기존 설치 인증을 사용한다.

광고 구분값·설치 ID·동의 시각을 연결하고 동의 이후 활성 이용·분석 성공·후보 선택·저장을 최대 90일간 집계한다. Google/Meta로 앱 이용 정보를 전송하지 않는다. 원고 내용을 광고 측정에 사용하지 않는다. 광고 연결 동의는 품질 검토 동의와 별개다.

일반 앱 아이콘 실행이나 선택 거절은 출처 미확인이다. 링크 공유/수정 가능성이 있어 광고 조회 사실의 검증이나 사람 수를 보장하지 않는다. 기존 설치/이용은 소급 귀속하지 않는다.

배포 조건: 서버 endpoint 배포 후 앱 0.2.4 이상 서명 릴리스. Windows/macOS에서 새 설치, 종료 상태 딥링크, 실행 중 딥링크, 거절, 동의, 분석 성공, 설정 철회를 실제 확인한 다음 랜딩 연결 버튼을 제공한다. 단위 테스트만으로 네이티브 수신 검증을 대체하지 않는다.
