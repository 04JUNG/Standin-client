# QA·보안·릴리스 기준

## 1. 지원 운영체제

최종 목표:

- Windows
- macOS

초기 개발은 주 개발 OS에서 우선하되, OS 종속 기능은 문서화한다.

확인할 항목:

- 파일 경로
- 캡처 권한
- 다중 모니터
- 전역 단축키
- 폴더 선택 대화상자 (설정의 기본 저장 폴더 변경, 저장 결과의 "다른 폴더에 저장")
- 저장 폴더 쓰기 권한 (macOS의 Documents·Downloads 접근)
- 앱 창에서 클립스튜디오 캔버스로 파일 드래그 (ADR-009 주 경로). 원본이 저장 폴더에 남는지 함께 확인
- 폴더 열기 → 탐색기에서 클립스튜디오로 드래그 (폴백)
- 창 최소화·복원
- Retina / DPI

## 2. 기능 테스트

### 인증

- 로그인 성공
- 로그인 실패
- 네트워크 실패
- 세션 복원
- 세션 만료
- 로그아웃
- 로그아웃 후 캐시 제거

### 입력

- 지원 파일
- 미지원 파일
- 큰 파일
- 손상 이미지
- drag/drop
- file picker
- 제거와 다시 선택

### 캡처

- 성공
- 취소
- 권한 거부
- 너무 작은 영역
- 저장 실패
- 다중 모니터
- 다른 DPI
- 임시 파일 정리

### 분석

- 업로드 실패
- 긴 처리
- Job 실패
- 재시도
- 다시 검색
- 후보가 5개 미만
- 후보가 없음

### 내보내기

- 다운로드 실패
- 설정된 저장 폴더가 삭제됨 → 다운로드 폴더로 되돌리기
- 폴더 권한 없음
- 같은 파일명 (덮어쓰지 않고 일련번호)
- "다른 폴더에 저장" 대화상자 취소
- 저장 후 폴더 열기
- 드래그 시작 실패 → 폴더 열기 안내
- 드래그 도중 취소 → 상태가 남지 않음
- 클립스튜디오 미설치 환경에서도 저장·폴더 열기가 정상 동작

## 3. 보안

### 토큰

- secure storage
- 로그 출력 금지
- logout 시 삭제
- refresh 실패 시 삭제

### 파일

- 업로드 전 MIME 검증
- 사용자 파일명 신뢰 금지
- 경로 traversal 방지
- temp 경로 앱 내부 제한
- 서버에서 받은 파일명 정리
- 실행 파일로 저장하지 않음

### 네트워크

- 운영 환경 HTTPS
- 인증 헤더
- timeout
- request ID 기록
- 민감한 request body 로그 금지

### Tauri 권한

- 최소 capability
- 필요하지 않은 shell 실행 권한 금지
- 임의 URL 열기 제한
- 파일 시스템 접근 범위 제한
- command input 검증

## 4. 개인정보

입력 콘티는 미공개 창작물일 수 있다.

앱과 웹에서 명확히 안내할 항목:

- 서버 전송 여부
- 저장 기간
- 모델 학습에 사용하는지
- 사용자가 삭제할 수 있는지
- 로그에 원본 이미지를 남기는지

MVP에서도 “자동으로 학습에 사용”한다고 가정하지 않는다. 서버 정책이 확정되기 전에는 문구를 작성하지 않는다.

## 5. 로깅

로그에 포함 가능:

- 앱 버전
- OS
- command 성공/실패 코드
- API request ID
- Job ID
- 처리 단계
- 오류 stack

로그에 포함 금지:

- 비밀번호
- access/refresh token
- 원본 이미지
- BVH 내용
- 전체 이메일
- 서버 응답의 민감 데이터

개발 로그와 사용자 진단 로그를 구분한다.

## 6. 성능 목표

- 앱 초기 화면 빠르게 표시
- 로그인 화면까지 불필요한 3D 번들 로드 금지
- 3D 뷰어는 lazy load
- 큰 이미지 미리보기 최적화
- 캡처 후 미리보기 지연 최소화
- Job polling으로 UI thread를 막지 않음
- 메모리 URL 정리

## 8. MVP 수용 기준

### 인증

- 올바른 사용자만 앱 화면 접근
- 로그아웃 후 사용자 데이터가 화면에 남지 않음

### 캡처

- 주 개발 OS에서 영역 캡처 가능
- 취소와 권한 거부를 구분
- 캡처가 업로드 입력으로 연결

### 분석

- Job 상태 확인
- 실패 재시도
- 완료 결과 표시

### 후보

- 최대 5개 후보 비교
- 하나 선택
- 다시 검색
- 선택 없이 저장 불가

### 저장

- BVH 로컬 저장
- 사용자 지정 경로
- 완료 확인
