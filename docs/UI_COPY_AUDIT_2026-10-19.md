# 사용자 안내 문구 및 결과 검색창 점검 — 2026-10-19

기준: `develop`의 `a301de9b7f5008b75807358dd0213841a877da52`. 문구 수정 전용 브랜치 `codex/user-friendly-ui-copy-20261019`에서 작업했다.

## 결과

- 정적 검색 범위: 클라이언트·네이티브 소스 296개 파일, 한국어 문자열/JSX/템플릿 조각 1380개. 개발 진단·mock 설명·Rust 테스트 단언도 포함한 수치이며, 사용자 문장 수나 수정 문장 수가 아니다.
- 실제 변경 기록: 프로덕션 54개 파일의 문구 변경 **195개 그룹**. 전후 항목 수가 다르면 한 그룹에 모두 기록했다. 아래 전체 표와 JSON이 기준이며, 중간 작업 문구는 포함하지 않는다.
- 버튼 `이 포즈 직접 선택` → `이 포즈 선택`; 선택 시 `선택한 포즈`. 스크린리더 이름에서도 `직접`을 없앴다.
- `문장 바꿔 검색하기` / `문장을 바꿔 검색하기` 링크 → 결과 안에서 바로 고칠 수 있는 검색창과 테두리가 있는 `다시 검색` 버튼. Enter로도 검색한다. 앱·플로팅 바 모두 적용한다.
- 새 검색 중에도 이전 카드를 볼 수 있다. 이전 결과임을 알리고, 새 검색 결과가 없거나 실패하면 기존 선택을 유지한다. 성공할 때만 새 결과로 이동하고 이전 포즈 선택을 비운다.
- 반복 주의 문구는 카드마다 표시하지 않고 결과 안내에 한 번 표시한다. 진행하지 않은 생성 단계의 `미실행` 설명은 표시하지 않는다.
- 기본 체형·대략적인 포즈·정면 참고라는 정보는 유지한다. 저장 전 최종 확인, 미리보기 전용, FBX/BVH 차이와 실제 제한도 유지한다.
- 업데이트·네이티브 저장·단축키 오류는 코드별 사용자 안내로 바꾼다. 내부 경로·호스트·OS 오류 원문을 그대로 보여주지 않는다.

## 점검 원칙과 유지한 항목

`관측`, `판정 보류`, `검증 미통과`, `스켈레톤`, `기하·의미 검색`, `렌더`, `서버 계약`, `전역 단축키` 등 구현 관점의 말을 사용자가 보는 상태와 다음 행동으로 풀었다. 이미 이해하기 쉬운 일반 버튼·설명은 유지했다. 코드·열거형·API 계약·후보 ID·권한은 번역하거나 바꾸지 않았다.

개인정보 동의·보관 기간, 실제 운영 한도와 제한, 실제 분석과 체험 모드의 구분은 유지했다. FBX/BVH와 운영체제 설정의 공식 이름처럼 선택에 필요한 용어도 유지했다. 서버가 제공하는 포즈 설명·체형 이름·사용자 작성 이름은 임의로 번역하지 않으며, 체형 이름이 빠진 일부 경로에서는 내부 ID를 노출하는 대신 기본 안내를 표시한다.

## 동작 및 검증 기록

- 검색 동작은 공통 `useSemanticSearch`로 묶었다. 기존 최대 500자, 서버가 알린 Top-K(10/20), 빈 검색 차단과 이전 요청 취소를 유지했다.
- 한글 조합 중 Enter는 검색하지 않는다. 입력 중 Enter가 포즈 확정 단축키로 전달되지 않게 막는다. 검색 중 연속 제출은 차단한다.
- 앱 검색 결과는 앱에서, 플로팅 바 검색 결과는 플로팅 바에서 이어진다.
- 검색 실패/빈 결과를 구분하고, 입력 수정·언마운트 후 늦게 도착한 결과는 적용하지 않는 테스트를 추가했다.
- 업데이트·저장·단축키의 네이티브 오류 원문을 노출하지 않는 테스트를 추가했다.
- 실제 컴포넌트로 720px·420px 폭의 격리된 로컬 화면에서 검색창·버튼·선택 문구·Enter 동작·이전 결과 안내를 확인했다. 이미지는 배치 확인용 단순 도형이며 실제 렌더 결과가 아니다.
- 설치 앱·스테이징 E2E·서버 배포·다른 세션의 워크트리에는 반영하지 않았다. 이 변경으로 이미지 생성 시간이나 검색 품질이 개선됐다고 주장하지 않는다.

최종 검사 결과는 파일 하단에 기록한다. Node 26의 실험적 Web Storage 때문에 테스트는 `NODE_OPTIONS=--no-experimental-webstorage npm test`로 실행한다. 패키지·설정 파일은 바꾸지 않는다.

- 변경 후: 두 옵션 활성화. 바 모드에서 HTML·body·root 배경을 함께 비우며, 라우트 전환 시 페인트 전에 배경 모드 갱신.

- 검증: 전체 테스트 838개 통과·기존 1개 건너뜀, typecheck·lint·웹 build·macOS `cargo check --locked --offline` 통과. 기존 큰 번들 경고 유지.

- 배포 참고: Tauri의 macOS 투명 창 지원은 private API를 사용하므로 현재 직접 설치 파일 배포 기준이다. Mac App Store 배포를 지원한다고 주장하지 않는다.
