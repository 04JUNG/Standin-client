# 광고에서 앱 사용까지

랜딩의 ‘설치했어요 — 앱 열기’는 production `standin://campaign` 딥링크를 전달한다. staging/dev는 각 환경의 프로토콜만 받는다. `source=instagram`, `campaign=open-beta`, `creative=meta-poster-a|meta-hook-a` 외 입력은 거절한다. 웹 쿠키·클릭 식별자·이메일은 받지 않는다. Windows의 `campaign/` 정규화는 v0.2.5부터 지원한다.

## 첫 실행 선택 (v0.2.6)

약관 화면에서 필수 약관, 선택적 품질 검토, 선택적 광고 통계를 구분한다. 체크박스는 기본 해제다. ‘전체 동의하고 시작’은 바로 위에 고지한 모든 항목을 명시적으로 선택한다. ‘선택한 항목만 동의하고 시작’은 필수 약관만 체크해도 가능하다. 광고 통계 거절로 기본 기능을 제한하지 않는다.

등록 성공 후 광고 통계 선택(설치 ID, 허용/거절, 선택 시각, 고지 버전)을 기기에 최대 90일 저장한다. 만료된 저장값은 다음 로드에서 삭제한다. 저장소 오류 때는 세션 동안만 유지한다. 다른 설치 ID에는 적용하지 않으며 전체 데이터 삭제 때 초기화한다. 기존 사용자의 선택을 추정하거나 소급 허용하지 않는다.

콜드 스타트(getCurrent)와 실행 중(onOpenUrl)을 처리한다. 첫 화면에서 허용한 설치는 추가 팝업 없이 연결하고, 거절한 설치는 링크를 폐기하고 전송하지 않는다. 선택 이력이 없는 기존 설치에는 별도 선택 안내를 유지한다. pending 소재는 메모리에만 둔다. 수집 목적은 광고 효과 측정이며, 설치 식별자와 이용을 연결하므로 익명 통계로 간주해 동의를 생략하지 않는다. 이는 현재 구현의 처리 기준이며 모든 분석에 동의가 필수라는 법률 판단은 아니다.

## 연결·철회·측정 한계

동의에 따른 POST `/v1/installations/current/acquisition`은 creative, consent=true, version=2026-10-29를 보낸다. 서버 동의 확인 시각은 실제 연결 요청 시각이며 첫 화면의 원래 선택 시각은 로컬에만 있다. 서버는 설치 등록 24시간 이내의 첫 연결만 인정한다. 실패해도 앱 이용은 계속 가능하며 설정에 오류를 표시한다.

설정의 ‘광고 유입 연결 해제’는 이후 자동 연결을 먼저 차단하고 진행 중인 연결 완료 후 DELETE하여 늦은 POST가 연결을 복원하지 못하게 한다. 서버 삭제 실패는 표시하고 재시도할 수 있다. 앱·작업은 유지한다. 조회·연결 API는 기존 설치 인증을 사용한다.

광고 구분값·설치 ID·동의 확인 시각을 연결하고 연결 이후 활성 이용·분석 성공·후보 선택·저장을 최대 90일간 집계한다. Google/Meta로 앱 이용 정보를 전송하지 않는다. 원고 내용을 광고 측정에 사용하지 않는다. 광고 연결 동의는 품질 검토 동의와 별개다. 철회·만료 후 광고 구분값을 삭제하며 재연결 방지용 시각은 설치 기록 삭제까지 남는다.

일반 아이콘 실행만으로는 출처를 알 수 없다. 링크 공유/수정 가능성이 있어 광고 조회 사실이나 고유 사람 수를 보장하지 않는다. 기존 설치/이용은 소급 귀속하지 않는다.

배포 전: 공개 측정 고지의 v0.2.6 첫 실행 선택 설명, 서명 빌드, 새 설치의 전체/개별 선택, 거절 시 무전송, 실행 중/종료 상태 링크 및 설정 철회를 확인한다. v0.2.5 Windows의 포스터 콜드 시작·영상 실행 중 전달은 실제 확인했다. macOS의 네이티브 전달은 별도 기기 검증이 필요하다.
