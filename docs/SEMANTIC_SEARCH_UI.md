# 문장으로 포즈 찾기 (2026-10-18)

홈·플로팅 바의 문장 검색→문장 입력→BFF 검색→설치 소유 서버 Job 결과→정식/근접 그룹→BVH 관절 3D 미리보기.
최신 추론 PR #96의 정식·근접 후보 계약을 BFF 표시 계약으로 받는다. 이전 PR #87의 미러 묶음·내보내기 계약을 가정하지 않는다.

입력 최대 500자, 한글 IME 조합 Enter 보호, 예시 칩은 입력만 한다. 입력 변경/이탈 시 요청을 취소하고 늦은 응답을 무시한다.
검색 준비·미지원·처리 중·오류·정상 빈 결과는 다르게 보여준다. 진행률이나 결과를 만들지 않는다.
문장을 URL/localStorage/analytics에 넣지 않는다. 결과가 있는 Job의 문장이 서버에 보관됨을 알린다.

문장 결과 화면은 이전 이미지 draft를 사용하지 않는다. 이미지·스켈레톤·인물 검출을 수행했다고 표시하지 않는다.
정식 검색 후보와 근접 참고 후보를 분리하고 점수를 정확도나 기하 거리로 표시하지 않는다.
카메라는 검색 정렬이 아닌 명시적 정면 참고다. BVH frame 0을 기존 관절 3D 뷰어로 확인한다.

자동 적용·refine·release 권한은 그대로 유지한다. 2026-10-19 수동 내보내기 계약을 지원하는 BFF가
등록 BVH와 해시를 확인해 `manualExportAllowed=true`를 주면, 정식·근접 그룹에서 사용자가 직접 고른 뒤
확정·최종 확인을 거쳐 BVH/FBX로 저장할 수 있다. 손 선택만으로 권한이 바뀌지는 않는다.
이 계약이 없는 구 BFF와 파일이 확인되지 않은 생성 후보는 미리보기 전용으로 유지한다.
상세한 최종 체형·손·출력 범위 및 receipt 검증은 [12_EXPORT_AND_SAVE_SPEC.md](12_EXPORT_AND_SAVE_SPEC.md)를 따른다.
손 카탈로그가 준비되면 인물 기준 손 선택과 조회 전용 PNG 렌더를 사용할 수 있다. PNG는 기본 체형·정면 참고이며,
원래 BVH 관절 미리보기에 손을 합성했다고 표시하지 않는다. 손 선택 뒤 확인 버튼을 눌러 새 렌더를 요청한다.

실제 API 연결은 mock 플래그 둘 다 false와 BFF staging 주소를 사용한다. 기존 구형 서버 동작은 유지한다.
