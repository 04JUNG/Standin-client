## 유지한 동작과 데이터

- 후보 ID·순위·원본/미러 연결·관측손/반대손 데이터와 권한·해시·검증 메타데이터는 변경하지 않는다.
- 이미지 클릭과 선택 버튼은 기존 콜백·선택 상태·비활성 조건을 유지한다. 저장 불가 후보를 승격하지 않는다.
- 포스터 source/hash/scope 검증과 자연어의 저장된 포스터·지연 로딩·연속 스크롤을 유지한다.
- 포스터 로딩·실패·재시도, 저장 실패 등 행동에 필요한 기존 피드백과 접근성 이름을 유지한다.
- `ReviewPage`, `BarReviewPage`, 손 hook, BFF, 아동 추천 정책 파일은 수정하지 않았다.

## 검증

- 관련 테스트 42개 통과. 이후 전체 테스트 885개 통과, 기존 실메시 사양이 필요한 테스트 1개 건너뜀.
- `npm run typecheck`, `npm run lint`, `npm run build`, 변경 파일 Prettier, `git diff --check` 통과. 기존 큰 번들 경고 유지.
- 실제 공통 컴포넌트를 localhost의 격리된 fixture에서 렌더해 전체 화면 러프 후보와 600px 플로팅 바 자연어 후보의 본문 제거·라벨·선택 버튼 배치를 확인했다. fixture 이미지는 기존 중립 체형 썸네일이며 실제 검색 포즈·스테이징 E2E의 증거가 아니다.
- 임시 localhost 서버·브라우저 탭을 정리했다. 설치 앱·스테이징을 조작하지 않았다.
