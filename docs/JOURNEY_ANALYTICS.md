# 웹 방문·앱 이용 경로 (v0.2.9)

`standin://journey?token=...`는 웹 쿠키 동의 후 발급된 30분 일회용 연결값입니다. 실행 환경별 URI scheme을 확인하고 알려진 host/path와 token 한 개만 허용합니다. 기존 `standin://campaign` 및 전용 설치 파일의 공통 소재 집계는 그대로 유지합니다.

앱의 기존 품질 검토/광고 연결 동의를 재사용하지 않습니다. 이 링크를 받은 앱은 새 목적과 항목을 설명하고 ‘연결하지 않고 계속’과 ‘동의하고 연결’을 제공합니다. 명시적 선택 이후 서버가 발급한 receipt에 묶어 이후의 고정된 단계 이름·시각만 보냅니다. 원고·검색어·파일 경로·작업 ID·quality properties는 전송하지 않습니다. 서버의 분석 요청/성공/실패는 연결 이후 작업만 조회됩니다.

큐는 최대 120건/24시간이며 서버 receipt가 달라지면 이전 큐를 재연결하지 않습니다. 서버 확인 전, 미동의, 철회, 만료에는 수집하지 않습니다. 네트워크 실패는 누락될 수 있고 마지막으로 저장된 화면을 실제 중단 원인으로 단정하지 않습니다. 앱 열기 자체는 신규 설치가 아닙니다.

설정의 ‘웹 방문·이용 경로 연결 해제’는 먼저 로컬 수집·큐를 중단하고 진행 중인 claim 뒤에서 서버 삭제를 실행합니다. 실패 시 삭제 대기를 저장해 다음 실행/네트워크 복구에서 재시도하며 서버 삭제 완료라고 표시하지 않습니다. 전체 앱 데이터 삭제도 링크를 삭제합니다. 웹 방문 기록 삭제는 웹 쿠키 설정에서 별도로 요청할 수 있습니다.

검증: `journeyClient.test.ts`의 URI/동의/속성 제한/철회 경합/오프라인 삭제/receipt 재할당 금지, 기존 analytics/acquisition 회귀, TypeScript·lint·build·release checks. 승인 후 Windows와 macOS 배포 빌드 및 실제 앱 handoff는 별도 확인해야 합니다.
